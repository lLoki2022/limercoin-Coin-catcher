# 🪙 Limercoin Coin Catcher

Автоматический кликер для браузерной игры **Limercoin / Coin Catcher**.

Скрипт отслеживает изображения, которые игра рисует через **HTML5 Canvas**, находит спрайт монеты размером `65x140` и автоматически отправляет по этим координатам `mousedown` + `mouseup`.

Спрайт бомбы размером `375x120` скрипт игнорирует.

## ✨ Возможности

- 🪙 обнаружение монет `65x140`;
- 🚫 игнорирование бомб `375x120`;
- 🖱️ автоматический `mousedown` + `mouseup`;
- 📐 преобразование координат Canvas в координаты экрана;
- ⏱️ защита от повторного клика по одной позиции в течение 300 мс;
- 🧹 автоматическая очистка старых координат;
- 🛑 остановка через `window.LIMER_STOP()`;
- 🔄 повторный запуск автоматически останавливает предыдущий экземпляр.

## 📋 Требования

- ПК и современный браузер;
- открытая игра Limercoin / Coin Catcher;
- игра должна использовать HTML5 `<canvas>` с 2D-контекстом.

Дополнительные программы и библиотеки не нужны.

## 🚀 Как запустить

1. Откройте игру в браузере.
2. Нажмите **F12** или **Ctrl + Shift + I**.
3. Откройте вкладку **Console / Консоль**.
4. Откройте файл [`limercoin-auto-click.js`](./limercoin-auto-click.js).
5. Скопируйте весь код.
6. Вставьте код в Console.
7. Нажмите **Enter**.

Если всё запустилось, в консоли появится:

```text
================================
🪙 LIMERCOIN AUTO CLICK
================================
✅ Монеты: 65x140
🚫 Бомбы: 375x120 — игнорируются
🖱️ mousedown + mouseup
================================
```

При обнаружении монеты будут появляться сообщения вида:

```text
🪙 CLICK Game: 123 456 Screen: 500 700
```

## 🛑 Как остановить

В Console выполните:

```js
window.LIMER_STOP()
```

После этого появится:

```text
🛑 Limercoin бот остановлен
```

## 🔄 Повторный запуск

Можно снова вставить скрипт в Console.

Перед запуском новый экземпляр автоматически выполнит:

```js
window.LIMER_STOP?.();
```

Поэтому предыдущий обработчик будет остановлен.

## ⚠️ Важно

Скрипт работает только в текущей открытой странице. После обновления страницы (`F5`) его необходимо запустить заново.

Скрипт рассчитан на текущую структуру игры и использует размеры изображений для определения объектов:

| Объект | Размер | Действие |
|---|---:|---|
| 🪙 Монета | `65x140` | Клик |
| 💣 Бомба | `375x120` | Игнор |

Если разработчики игры изменят Canvas, размеры спрайтов или способ отрисовки объектов, скрипт может перестать работать.

> ⚠️ Используйте скрипт только там, где автоматизация разрешена правилами игры/сайта. Ответственность за использование скрипта лежит на пользователе.
